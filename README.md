# Pocket Football Arena

Single-file, mobile-first 2D football game (plain Canvas, no build step).

## Run
Open `index.html` in a modern browser. On a phone, host the folder (any static server) and open it in landscape.

## Controls
- Touch: drag the left side to move; SHOOT (hold, release), PASS, SPRINT, TACKLE, SWITCH on the right.
- Keyboard: WASD/arrows, J shoot, K pass, Shift sprint, L tackle, Q switch, P pause.
- Gamepad: left stick, A shoot, X pass, B/RT sprint, Y tackle, LB switch.
